# Supported games

Each game uses its own DLL. Choose the download for your game; each ZIP includes the listed DLL, loader, configuration and installation instructions.

- [The Suffering (2004)](https://github.com/Tiger-Fury/RetroInput-Public/releases/download/v1.0.1/RetroInput-The-Suffering-v1.0.1-Win32.zip) — `SufferingXInput.dll`
- [The Suffering: Ties That Bind (2005)](https://github.com/Tiger-Fury/RetroInput-Public/releases/download/v1.0.1/RetroInput-The-Suffering-Ties-That-Bind-v1.0.1-Win32.zip) — `SufferingTTBInput.dll`

See [installation instructions](INSTALLATION.md) and [supported controllers](SUPPORTED_CONTROLLERS.md). [Release notes and checksums](https://github.com/Tiger-Fury/RetroInput-Public/releases/tag/v1.0.1) are available on the release page.
